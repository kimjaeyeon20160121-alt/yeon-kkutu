연끄투 익명 계정 상점 패치

1) 연끄투 서버를 완전히 종료하세요.
2) ZIP 내부 lib 폴더를 C:\KKuTu\Server 안에 압축 해제해 동일 이름 파일을 덮어쓰세요.
3) 서버를 다시 시작하고 http://127.0.0.1/?server=0 접속.

로그인하지 않아도 게스트 이름으로 입장, 구매/장착/판매가 기존 회원 방식으로 처리됩니다. 새 게스트 시작 게임머니는 0원입니다. 기존 회원 로그인은 유지됩니다. 브라우저 쿠키 삭제 또는 브라우저 변경 시 게스트 계정이 바뀝니다. 서버가 생성하는 lib\Web\.yeon_guest_secret 파일을 삭제하면 기존 게스트에 재접속할 수 없습니다.

기존 1.5배속 음악 브라우저 JS 및 바보모드 게임파일은 수정하지 않았습니다. 이 패치는 문법 검사를 통과했으나 실제 사용자의 서버에 설치하여 작동 테스트한 것은 아닙니다.
