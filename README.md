# 🎮 연끄투 | Yeon-KKuTu

**한국어 단어 게임을 더욱 재미있게!**

연끄투(Yeon-KKuTu)는 오픈소스 단어 게임 프로젝트 **끄투(KKuTu)**를 기반으로 제작 중인 웹 기반 멀티플레이 단어 게임 서버입니다.

한국어 끝말잇기를 비롯한 다양한 단어 게임을 지원하며, 사용자 편의성과 게임 환경 개선을 목표로 개발하고 있습니다.

연끄투는 한국어 단어를 활용하여 친구들과 함께 즐길 수 있는 온라인 게임 프로젝트입니다.

기존 끄투의 게임 시스템을 기반으로 하면서, 새로운 기능과 사용자 인터페이스 개선을 통해 보다 편리하고 재미있는 게임 환경을 만드는 것을 목표로 합니다.

## 🎮 게임 기능

### 1. 한국어 단어 게임

끝말잇기를 포함한 여러 종류의 단어 게임을 즐길 수 있습니다.

### 2. 멀티플레이 게임

게임방을 만들고 다른 사용자들과 함께 게임을 진행할 수 있습니다.

### 3. 바보모드 연습

게임 연습을 위한 바보모드 기능을 제공합니다.

### 4. 사용자 로그인

사용자별 로그인 기능을 통해 게임을 이용할 수 있습니다.

### 5. 게임방 관리

게임방 생성, 입장 및 게임 진행 기능을 지원합니다.

### 6. 관리자 기능

서버 및 게임 운영을 위한 관리자 관련 기능을 포함합니다. 일부 기능은 개발 및 점검 중입니다.

## 🚀 개발 환경 및 실행 안내

현재 연끄투는 Windows 개발 환경에서 운영 및 테스트하고 있습니다.

### 기본 준비 사항

- Node.js
- PostgreSQL
- Git
- 프로젝트에 필요한 npm 패키지
- 서버별 환경 설정 파일

### 개발 환경 실행 예시

프로젝트의 서버 설정과 데이터베이스가 준비된 상태에서 다음 명령어를 사용할 수 있습니다.

**게임 서버**

```cmd
node lib\Game\cluster.js 0 1
```

**웹 서버**

```cmd
node lib\Web\cluster.js 1
```

**Cloudflare 연결 프록시**

```cmd
node cloudflare-proxy.js
```

> 위 명령어는 현재 개발 환경 기준의 실행 예시입니다. 단순히 저장소를 복제하는 것만으로 서버가 즉시 실행되는 것은 아닙니다. 필요한 패키지와 환경 설정, 데이터베이스를 별도로 준비해야 합니다.
